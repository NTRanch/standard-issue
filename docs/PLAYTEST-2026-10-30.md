# Playtest record — Standard Issue v1.0.0 (2026-10-30)

Automated playtest of record for the sandbox build (the UE 5.8 /
seahawk exam session on primo is the scheduled follow-up, see
BREAKAGE-LOG).

## Method

- `node tools/playtest.mjs`: the shipped wasm core in demo mode sits
  each exam. Pass = victory, with the book reading the expected tier
  (T1 for the single-paper exams, T2 for the T-Gate sitting).
- Native runner (`build/test_core`): 469 checks over the identical
  core translation unit — validation (teach/arm flow, rep counting,
  signal reproduction, the full T-Gate sitting, T-gate arithmetic)
  and adversarial (the plug refusing everything but the phrase, a
  wrong signal not counted, clock expiry, the book keeping a pass
  through a failed sitting, determinism, draw-list bounds).
- `node tools/settings-check.mjs`: settings + book bridges
  round-trip; tier arithmetic reads through the bridge; settings
  reachable from boot, ungated.
- `node tools/perf.mjs`: step budget.
- D-221 visual spot check: frames extracted from the final preview
  MP4s at viewing size and inspected — SHOULD: the Fit gauge's zone
  and needle unmissable, the flashed glyph huge and legible, reps
  and the count readable. First pass found the needle invisible
  (breakage B-1); fixed, re-captured, re-inspected PASS. The
  raster-advance audit over all screens is CLEAN.

## Results
